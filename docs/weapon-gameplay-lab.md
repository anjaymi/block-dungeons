# 武器玩法实验版 0.1

日期：2026-10-03。基线：`2b1f9348bc72b26c56291a3c0a9228c6490ac8c8`。

这次交付是三个可执行的武器玩法原型，不是又一份数值建议。原版 `index.html`、`block-dungeons.html`、装备、掉落、存档与音效文件均不改动。实验入口为仓库根目录的 `weapon-lab.html`。

## 如何进入

GitHub Pages 部署完成后，访问与原版同目录的 `/weapon-lab.html`。源码提交成功不代表 Pages 已完成部署。

本地运行：在仓库根目录执行 `python -m http.server 8000`，打开 `http://localhost:8000/weapon-lab.html`。实验入口使用同源 iframe，在原版完成加载后安装独立玩法模块，因此实验入口不能直接通过 `file://` 双击使用；原版的双击方式不受影响。

进入准备界面后选择巨剑、双镰或战锤。入口的三个按钮可以预选武器并重新载入游戏；已经开始运行时会先提示当前局将清空。手机沿用攻击按钮，不增加新的必需按键。

## 这次真正增加的玩法

共同操作：第二击结束后，松开攻击至少约 0.14 秒，看到“变招就绪”后再次攻击。窗口从第二击后摇开始计算，约 0.85 秒后失效。持续按住仍走基础连段；快速连点不能累计松手时长。必须有就绪后的新按下事件，不能靠旧输入自动触发。

### 巨剑：破阵重劈

第二击之后主动变招，跳过正常旋风，完成较窄的定向重劈。目标需要处于前方攻击线且视线可达；不会同时放出原终结段的范围震波。收益是集中打击，代价是放弃环绕覆盖。

### 双镰：勾回剪击

尝试勾住前方狭窄走廊内最近的目标，将可拉动的轻型敌人拉近，随后在近身范围剪击。一次最多拉近 1.5 世界单位，不是瞬移。拉动会受到墙、箱子、其他单位和玩家身体的阻挡；不能越过前方重型敌人，精准抓取其后方的小怪。重型目标勾不动，但在剪击范围内仍会受到攻击。翻滚或中断该次攻击会结束拉动。

### 战锤：撞阵横砸

横砸前方第一名目标。幸存的轻型敌人可被沿攻击方向打出，最大距离约 2.8 世界单位。撞墙或撞到另一名敌人，只结算一次碰撞伤害与短暂失衡；其他敌人不会继承弹射，不能递归清场。直接击杀不抛飞尸体。碰撞伤害在出手时确定，不会因随后换装而变大。

Boss、石像巨人、树人、幽灵、传送型敌人，以及超出重量或离地条件的目标，不参与新增拉动和抛飞。Boss 可受到新增攻击的伤害，但新增分支会保留其动作与位移状态，不赋予额外打断能力。

## 保留与取舍

原版入口保持不变。实验模块只通过原版已有攻击、移动、命中、动画和换组入口扩展规则，不建立第二套装备或伤害属性系统。

原版近战伤害、词缀和命中特效继续处理分支的直接命中。战锤碰撞作为一次独立的受限伤害，不重新进入武器词缀触发链。

为留出真实选择窗口，实验版三类武器具有最短连续接招恢复：双镰 0.07 秒，巨剑与战锤 0.10 秒，分支动作 0.18 秒。这些是实验参数，不是完成平衡测试后的定值。改变的是最早接招许可，不要求每刀等待整段后摇。

攻击期间的换组请求延后到合法恢复点处理。暂停、离地、翻滚、切换武器身份、换层、窗口失焦会清除或限制准备状态。主动打飞已产生的碰撞不会从新武器读取属性。

## 已执行的检查与未完成的验收

执行命令：

```sh
node --check weapon-gameplay.js
node --test tests/weapon-gameplay.test.cjs
```

45 项自动化测试通过：包含输入窗口、普通连点、身份变化、方向筛选、圆形扫掠与墙角、重型目标阻挡、单次碰撞、伤害来源冻结、Boss 动作保留、换层清理、手机攻击入口和换组排队。

其中几何与输入测试直接执行实际模块；集成测试执行真实适配器，但原版部分入口用明确的测试替身提供。它们不是完整游戏试玩，也不能证明真实动画、全部音效包装、所有怪物和高攻速组合均无问题。

当前执行环境无法通过网络下载整份游戏到本地，因此未完成原版整页的浏览器试玩、桌面/手机真实操作、帧率评测和武器强弱验收。不要把本版直接标成“完整验收通过”。

## 本批没有实现的内容

没有宣称完成每把武器的两个互斥肉鸽改造，也没有改掉落、数值词缀、法杖布球、盾刀反击或铁剑侧切。没有把旧版所有结算问题一并修复，包括此前审查提到的匕首流血路径。先验证三个核心原型，再决定是否并入默认入口。

## 人工验收清单

用同一房间分别验证：第二击后收势是否容易主动触发；普通连点是否误触；巨剑能否主动选择旋风或定向重劈；双镰能否拉近射手但不能越墙越人；战锤能否利用墙和敌人排列且不会重复碰撞。

至少检查狭窄门口、贴墙、目标在途中死亡、玩家翻滚、暂停、换层、高攻速、触屏和低帧率。查看提示时不能要求玩家离开战场寻找新进度条。若长时间只按住一种攻击就总是更优，应调整招式覆盖或风险，而不是先加伤害。

回退方式：返回 `block-dungeons.html` 即回到完全未修改的原版。不要在一局进行中卸载模块；重新加载原入口即可。
