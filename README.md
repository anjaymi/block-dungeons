# 方块暗黑肉鸽 · Block Dungeons

Three.js 体素风俯视角暗黑肉鸽。单页 HTML，无需构建。

**在线试玩：** https://anjaymi.github.io/block-dungeons/

## 操作
- WASD 移动 · 左键连击 · 右键射箭 · R / 中键魔法 · 空格跳跃
- Shift 翻滚 / 按住奔跑 · Q 职业技能 · 1 2 3 神器 · 4 5 6 法师技能
- E 药水 · F 拾取 · I 背包 · M 地图 · X 换武器组 · Alt 显示掉落 · N 静音 · [ ] 音量

## 本地运行
直接双击 `block-dungeons.html`，或在目录下 `npx serve` 后访问。
