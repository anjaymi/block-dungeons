# 装备与背包概念参考 · 2026-10-03

- `equipment-backpack-pc-selected.png`：用户选定的 PC 视觉参考，来自本轮附件。
- `equipment-backpack-mobile-concept.png`：据此生成的横屏手机概念修正版，使用内置 ImageGen；用户选择第二版并授权开始落地，已接入游戏背包界面。

手机版保留黑铁金边、角色装备区和 10×4 背包；详细属性、赫拉迪克方块与套装说明收进可展开入口，操作提示改成触屏方式。修正版纠正了初稿的背包列数与重复手套槽，保留两个戒指槽。

概念图的像素位置仅作视觉参考。实现时须用真实数据维持 40 个背包格、10 个装备槽、物品占格与双手武器占用关系，并在实际手机视口核验可读性和触摸目标；不能把整张概念图当作可点击的游戏界面。

实现由 `inventory-layout.js`、`inventory-assets.js`、`inventory-controller.js` 和 `inventory-ui.js` 连接原有背包逻辑。21 项背包回归通过，原生 Canvas 画面及同尺寸参考比较见 `../inventory/qa/`；浏览器和实机验证状态见项目根目录 `design-qa.md`。

生成方式：选定 PC 图作为参考，先生成 844:390 横屏比例的手机版，再针对背包格子和戒指槽编辑修正；背景保持不透明。
