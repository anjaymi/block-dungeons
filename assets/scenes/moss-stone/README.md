# 苔石地牢建筑素材

本轮制作了缺角大石板、斜裂石板、破角石板、带墙脚和四块压顶石的墙体、分层柱台及小碎石。原生 Blockbench 5.2.1 / MCP 1.10.0 创建并导出 `moss-stone.bbmodel`，在独立项目中重新导入，检查了正面、背面、44 个网格与嵌入贴图。`palette.png` 为项目自制调色板，无外部贴图素材。

`scene-assets.js` 是程序模型的权威源；`tests/build-scene-assets.cjs` 生成调色板、逐网格模型数据及 MCP 输入。执行 `node tests/build-scene-assets.cjs` 可重新生成数据。`source-layout.json` 的摆放偏移仅用于素材预览；游戏按单个素材的局部坐标建模，不使用预览偏移。

游戏使用原有 Three 地形合批链路，从同一几何源生成顶点颜色网格。`bbmodel` 是可编辑的原生资产交付，不在每帧重新解析。Blockbench 中的新造型修改需要同步回 `scene-assets.js`，再重新生成、导出与核验。

游戏坐标为 X/Y 水平、Z 向上，每格 24 单位；Blockbench 坐标转换为 `[x,z,-y]`。石板最高点为 0，底层覆盖整格；墙体仍限定在原格内，高度为原墙高加 2 单位压顶；柱台底面接地。原生项目编解码将顶点保留到五位小数，核验最大误差小于 0.000005 单位。调色板为 104×16，UV 尺寸配套，重新导入后的贴图和调色板逐像素相同。

视觉参照是用户已打开的[试玩视频](https://www.bilibili.com/video/BV1Z9ar6FEqq/)中约 1:52 与 2:21 的石材边界、植物聚簇、石台和局部暖光。本素材是为方块地牢独立制作的造型，没有使用视频中的游戏模型或贴图。参考帧与实际游戏、固定房间对照在 `assets/render-qa/scene-style/`；技术及视觉检查见 `review.json`。参考片段主要是户外据点，本轮将其大形状与边缘层次用于原有冷色地牢。
